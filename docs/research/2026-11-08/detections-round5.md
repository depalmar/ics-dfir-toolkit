## Decisions and rejected options

- **T0801 and ICS-HUNT-0002.** HUNT-0002 already covers a new host polling
  controllers on an industrial port (FrostyGoop's flow-level signal). Rather
  than duplicate it, ICS-HUNT-0020 carries T0801 on Mandiant's own TAGRUN
  mapping (OPC UA value reads from irregular clients) and points to
  HUNT-0002 for Modbus. The cleaner fix for FrostyGoop is a one-line edit
  to HUNT-0002 (below), which this stream may not make.
- **T0835/T0877 on a logic comparison.** Round 3 rejected tagging a generic
  logic comparison with these techniques. The detection here is not generic:
  it names Symantec's block numbers and Symantec's own statement that an
  infected PLC is recognised "in a clean environment" from OB1 and OB35, and
  MITRE's T0835/T0877 procedures quote the same passages. Its notes say it
  finds the blocks that carry the techniques, not the acts.
- **T0840 vs T0846.** CISA maps Havex's WNet discovery to T0846; the
  repository's Havex record maps its enumeration of connected network
  resources to T0840. HUNT-0020 carries both and says so.
- **No Sigma pattern on Sysmon's SignatureStatus.** Microsoft documents that
  Sysmon records signature information and checks revocation, but not the
  exact strings it writes; the revoked-signer test is a review step.
- **No rule for an ISO inserted into an existing virtual CD-ROM drive.**
  Whether Windows raises 6416 for that is not documented; HUNT-0019 sends
  the analyst to the hypervisor's media history instead.
- **No AutoRun policy path.** Mandiant says the SCADA host permitted CD-ROM
  autorun; Microsoft's policy path was not read, so the hunt asks for it to
  be confirmed before anyone changes a qualified HMI.
- **No Cimplicity log file name or HMI web port.** CISA shows the log's
  columns but not its name or location; neither is guessed.
- **Published indicators not retyped.** The attacker IP addresses in CISA's
  Cimplicity log example and Mandiant's appendix are left in the sources;
  rule comments say they exist without copying them.
- **No Mandiant or CISA rule text copied.** Mandiant's Sigma/YARA-L on the
  Sandworm page and CISA's BlackEnergy YARA are pointed to, not vendored.
